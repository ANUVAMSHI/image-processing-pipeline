2. SYSTEM ARCHITECTURE & ENGINEERING HIGHLIGHTS
--------------------------------------------------------------------------------
• Non-Blocking Ingestion Pipeline:
  Built with Python (FastAPI + SQLAlchemy + OpenCV + PyTesseract). Validates file
  magic bytes (`FF D8 FF`), returns HTTP 202 Accepted immediately, and enqueues
  processing tasks without blocking the main event loop.

• Asynchronous Task Queue & Worker Threads:
  Heavy computer vision analysis is offloaded to worker threads via asyncio.to_thread,
  equipped with Exponential Backoff Retries (2s, 4s, 8s delays) for resilience.

• 8 Multi-Modal Quality & Anomaly Heuristics:
  1. Magic Byte Header Security Inspection (MIME spoofing defense)
  2. Laplacian Blur Score Calculation (variance < 100.0)
  3. Multi-Space Lighting & Contrast Analysis (HSV Luminance)
  4. 64-bit Perceptual Hash (dHash) Duplicate Photo Prevention
  5. Indian Vehicle Registration OCR & Format Validation (MH12NW8556, TN05BT5754)
  6. Resolution & Aspect Ratio Validation
  7. EXIF Metadata & Screenshot Software Tampering Detection
  8. Quality Verdict Classification (PASS, WARNING, REJECT)

• Enterprise Dashboard & Queue Management:
  Features real-time polling, single-item deletion (`DELETE /api/v1/images/{id}`),
  bulk queue purge (`DELETE /api/v1/images/clear-all`), and IP rate-limiting.
